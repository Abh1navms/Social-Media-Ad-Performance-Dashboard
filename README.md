# 📊 Social Media Ad Performance Dashboard Analysis

## Project Overview

This project is a comprehensive data analysis of a marketing campaign performance dashboard. It demonstrates skills in monitoring complex performance metrics, identifying critical temporal patterns (time-series analysis), and providing strategic recommendations for resource optimization. The analysis focuses on identifying a critical budget-seasonality misalignment and pinpointing the core audience segment for maximum Return on Investment (ROI).

## 🎯 Key Insights (Expert Analysis)

A detailed, expert analysis of the data reveals several critical and actionable insights:

*   **Critical Budget Misalignment (Anomaly Detection):** The largest campaign budgets are currently allocated to "Winter" campaigns, which coincide with the lowest engagement months (Q1/Q4). This represents a major opportunity for budget reallocation to the peak season.
*   **Core Target Audience:** The most engaged segment is the **Male 25-34** age group (12.1K engagements), followed by **Male 18-24** (9.2K). Future campaigns should be laser-focused on the **Male 18-34** demographic.
*   **Creative Effectiveness:** **Stories** remain the highest-performing ad format, significantly outperforming Video. This format should be prioritized for creative development.
*   **Seasonal Peak:** Engagement is highly seasonal, peaking sharply between **May and July**, with July showing the highest overall engagement.
*   **Optimal Timing:** The highest engagement occurs on **Wednesday** during the **Evening** hours.

## 🚀 Strategic Recommendations

Based on the analysis, the following strategic actions are recommended to maximize campaign ROI:

1.  **Reallocate Budget to Peak Season (May-July):** Shift funds from low-engagement Winter periods to the high-activity Summer months to capitalize on proven audience behavior.
2.  **Laser-Focus on Male 18-34 Demographic:** Concentrate creative and media spend on this core segment, which drives the highest engagement.
3.  **Prioritize "Stories" Ad Format:** Leverage the audience's preferred content consumption method by making "Stories" the primary creative vehicle.
4.  **Optimize Scheduling:** Implement a tactical boost in ad spend on **Wednesday evenings** to capture the peak daily engagement window.
